# Sontify project status

## Current deliverable
Native Android source project, Kotlin + Jetpack Compose.

## Implemented in source
- App shell and five-tab navigation.
- Local audio file discovery via MediaStore permission.
- Real local audio playback via AndroidX Media3 ExoPlayer.
- Play/pause and stop.
- Mini-player UI.
- Local playlist-name persistence.

## Not yet implemented
- Cloud authentication / synced user profiles.
- Online streaming catalog and licensing.
- Full favorites workflow and track-based playlists.
- Background media service / lock-screen controls.
- Queue, shuffle, repeat, seeking, lyrics, sleep timer, crossfade.
- Friends/social, notifications, artist portal, royalties, payouts.
- Subscription billing, offline licensed downloads, ad system.
- Admin, moderation, copyright workflows, support chat.
- Production signing and Play Store release.

No fake online tracks, stream counts, earnings, or subscription transactions are included.
